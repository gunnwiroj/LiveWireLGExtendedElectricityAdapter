title=LiveWire + LG Extended Electricity Adapter
description=[h1]LiveWire + LG Extended Electricity Adapter[/h1]
description=
description=[b]This mod is only required if you use both LiveWire and LG Extended Electricity.[/b]
description=
description=Keep LiveWire's inverter coverage working when [b]LG Extended Electricity (LGEE)[/b]'s generator-range takeover is enabled. This lightweight compatibility adapter lets LiveWire's inverters continue to provide their normal radius-based power coverage alongside LGEE.
description=
description=[h2]Requirements[/h2]
description=
description=[list]
description=[*]Project Zomboid Build 42.21
description=[*]LiveWire (Mod ID: [code]batman_LiveWire[/code])
description=[*]LG Extended Electricity (Mod ID: [code]LGExtendedElectricity[/code])
description=[/list]
description=
description=The adapter declares both mods as dependencies. Enable them together with this adapter.
description=
description=[h2]Installation[/h2]
description=
description=[list=1]
description=[*]Subscribe to LiveWire and LG Extended Electricity.
description=[*]Subscribe to this adapter.
description=[*]In the Mods menu, enable LiveWire, LG Extended Electricity, and [b]LiveWire + LG Extended Electricity Adapter[/b].
description=[/list]
description=
description=For multiplayer, install and enable the adapter on the server and clients. Configure sandbox options on the server.
description=
description=[h2]Sandbox settings[/h2]
description=
description=When LGEE's generator-range takeover is active, the adapter offers one setting under [b]LiveWire + LG Extended Electricity[/b]:
description=
description=[list]
description=[*][b]LiveWire power range override:[/b] 0–100 tiles
description=[/list]
description=
description=The default value [b]0[/b] uses the 20-tile horizontal default. Choose a positive value to override the horizontal range. Vertical reach stays at the default of 3 floors while the takeover is active; there is no vertical override setting. When LGEE's takeover is inactive, LiveWire's original range behavior is left unchanged.
description=
description=[h2]What this adapter does[/h2]
description=
description=[list]
description=[*]Preserves LiveWire's inverter radius coverage while LGEE's generator-range takeover is active.
description=[*]Integrates coverage through LGEE's relay system automatically. No relay crafting, placement, or wiring is needed for LiveWire.
description=[*]Keeps coverage limited to LiveWire's configured horizontal radius and 3-floor vertical range while takeover is active; it does not power an entire building.
description=[*]Avoids missing squares and squares that already contain a generator.
description=[*]If compatible LGEE coverage APIs are unavailable, logs a warning and leaves LiveWire's original range behavior in place.
description=[/list]
description=
